
# ♻️ Garbage Management System

A Python-based Garbage Management System designed to analyze, visualize, and manage waste data efficiently.

## 🚀 Features
- Waste data analysis using CSV files
- Interactive dashboards
- Waste trend visualization
- Map-based waste location analysis
- HTML-based frontend pages

## 🛠️ Technologies Used
- Python
- HTML, CSS
- CSV Data Analysis
- Data Visualization Libraries
- Git & GitHub

## 📂 Project Structure
- `templates/` – HTML templates
- `uploads/` – Uploaded files
- `*.py` – Python backend scripts
- `*.csv` – Waste datasets
- `*.html` – Frontend pages
